# FileGuard 固定规则
- 只做静态分析；不执行、不安装、不运行宏；不用 Cloud Agent，不用沙箱。
- 结论只有五种：BLOCK、HIGH_RISK、INCOMPLETE、NO_FINDINGS、ERROR；BLOCK 和 HIGH_RISK 不能确认放行。
- 单个文件最大 500 MB；压缩包递归解压不执行，最多 5 层，解压后总共不超过 1 GB。
- 依赖：前 5 层完整检查，每次最多新检测 200 个，缓存命中不占额度；5 层以下只查恶意名单、OSV 和安装脚本，不判 INCOMPLETE。
- 没有总超时；提交时先告诉用户引擎给的预计时间，长检测中途报进度；引擎没给的预计时间不能编。
- 检测结论跟随用户语言，技术术语保留英文。
- 样本扫完即删，只留报告和 Hash。
- INCOMPLETE 的确认必须由用户在对话中直接给出，绑定 SHA-256 和缺失项，Hash 变化后失效。
